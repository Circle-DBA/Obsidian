## 一、先贴这段「术语设定」（笔记里强调的第一步）

```
你是一名资深前端架构师 + UI 设计师，正在帮我做一个中后台 Dashboard。
请严格遵循以下术语来理解我的需求，不要自行替换成其他方案：
- "顶栏" = TopBar，位于内容区顶部
- "侧栏" = Sidebar，位于内容区左侧或右侧
- "当前项" = 当前路由对应的菜单项（active item）
- "竖轨" = rail，只放图标的窄条导航
- "悬停提示" = tooltip，hover 时浮现的标签
- "快捷操作" = quick actions，高频动作的入口按钮
设计基调：浅色模式，灰白冷调，参考 shadcn-admin；不要深色模式，不要 antd。
技术栈：React 18 + TypeScript + Tailwind + shadcn/ui + react-router-dom v6。
```

## 二、6 种菜单的独立提示词（每条可单独贴）

### ① 透明顶栏

```
把后台的顶部导航做成"透明顶栏"：
- TopBar 背景默认 transparent，不要实心底色
- 页面滚动超过 80px 后，自动切换为 bg-white/80 + backdrop-blur-md + 底部 1px 边框 #E5E7EB
- 首屏 hero 区域（带渐变或大图）能从顶栏下方透出来
- 顶栏内只放：左侧面包屑、右侧搜索框 + 通知铃铛 + 用户头像
- 不要左侧 Sidebar，一级菜单改为顶部横向排列，二级用下拉
```

### ② 当前项展开文字（手风琴侧栏）

```
做一个自适应宽度的 Sidebar：
- 默认宽度 64px，只渲染 20×20 的 Lucide 图标
- 当前路由所在的一级项自动展开到 220px，显示图标 + 14px 文字
- 其他项保持 64px 收起，hover 时用 Tooltip 显示名称
- 路由切换时，旧项收回、新项展开，width 用 200ms ease-out 过渡
- 父项有子菜单时，展开后子菜单垂直缩进 16px 排列
- 数据源用一个 menuConfig 数组驱动，不要写死 JSX
```

### ③ 右侧竖轨菜单

```
把导航放在页面右侧，做成"右侧竖轨菜单"：
- 右侧固定 56px 宽的图标轨道，垂直排列一级菜单
- 左侧和中间全部留给内容区（日历 / 排期表 / 看板）
- 顶栏仍在顶部，左侧只放 logo + 全局搜索
- 当前项不要整行高亮，用轨道左侧一条 3px 的蓝色竖线标记
- 点击图标在右侧滑出 200px 的二级浮层
```

### ④ 图标菜单配大标题

```
做一个极窄图标 Sidebar（72px）+ 页面大标题模式：
- Sidebar 只放图标，没有任何文字 label
- 内容区顶部用 28px 加粗的页面标题（如"订单管理"），下方一行 14px 灰色描述文字
- 当前项图标容器背景 #E8EDF3，图标变品牌蓝，不要左侧竖条
- 一级菜单数量不超过 8 个
- 大标题根据路由自动切换（从 menuConfig 读取）
```

### ⑤ 图标轨 + 悬停提示

```
做一个常驻 56px 的图标轨 Sidebar：
- 所有菜单项都只显示图标，包括当前项
- hover 任意项时，从右侧弹出 180px 宽的浮层面板，显示该项所有子菜单
- 浮层 shadow-md + 圆角 8px + 150ms 淡入
- 当前项图标用品牌蓝填充（fill），未选中用 stroke 1.5 灰色
- Sidebar 上不要保留任何常驻文字，极致省横向空间
```

### ⑥ 菜单旁放快捷操作

```
在 Sidebar 底部固定一个"快捷操作"卡片：
- 卡片吸底（sticky bottom-4），滚动菜单时不跟着滚
- 内含 3 个高频动作按钮：新建订单、导出报表、邀请成员
- 每个按钮 = 小图标 + 12px 文字，bg-gray-50 hover:bg-gray-100
- 点击分别触发：新建弹窗 / 导出 CSV / 邀请链接复制
- 不要把这些动作放到 TopBar 右侧
```

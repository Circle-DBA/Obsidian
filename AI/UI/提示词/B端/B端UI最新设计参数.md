## 二、网页端画布定义（第2张）

PC 网页端画布分三种规格：

|   |   |   |
|---|---|---|
|画布类型|尺寸|说明|
|最小画布|**1280 × 800**|适配普通14寸或以下尺寸笔记本屏幕，确保完整展示布局内容|
|最佳画布|**1440 × 900**|最合适的尺寸，布局和排版不太复杂时向下自适应到1280难度小，能保证主流中小屏显示效果|
|最大画布|**1920 × 1080**|难以向小屏适配，只有确定使用场景都是大屏且全屏观看时才适合|

**小Tips**：网页端画布创建的核心考虑要点是——**最低适配大小**。小画布往大适配容易，大画布往小适配有一堆问题，所以轻易不会使用 1920 宽画布。

## 三、中英文字体选择（第3张）

### 中文字体

推荐：**苹方、微软雅黑、思源黑体、其它黑体（MISans）**

> 网页的中文字体通常直接调用系统默认字体，无法保证用户本地也有设计使用的字体。所以设计稿应用的字体只是参数效果示意，选择主流的黑体即可。

### 英文 / 数字字体

推荐：**Arial、Helvetica、SF Pro、Roboto**

> 英文字体同理，尽量使用常见英文黑体即可。

## 四、文本参数（第4张）

|   |   |   |
|---|---|---|
|项目|参数|说明|
|中英文最小字号|**12 / 10**|中文最小字号是12（浏览器也有一定限制），英文和数字约10；中英文注释字号在10-13之间|
|正文字号|**13-16**|再小难以看清，再大占用空间过多不符合B端场景|
|标题字号|**13-24**|标题包含不同等级所以尺寸跨度较大，极少数情况使用超过24的特大标题|
|字重设置|**Light、Medium、Bold**|只需要挑选细体、默认、粗体三个代表字重即可|
|字间距设置|**0**|浏览器渲染字体方式和移动端系统不同，不需要设计师自己修改文字间距|
|行高设置|**1.2 - 1.8 字号**|信息密集的极端场景单行文本用1.2倍行高；多行文本最大应用字号1.8倍行高|

## 五、图标参数（第5张）

图标是B端设计最重要的部分之一，整体设计风格不会像移动端那么花哨，但需要非常注意图标的尺寸控制与统一。

|   |   |   |
|---|---|---|
|图标类型|尺寸|说明|
|小图标|**12-20**|权重较低且应用于控件内的简约小图标，尺寸不会大于20|
|常规图标|**24-40**|使用频率最高的工具图标，往往也会作为按钮使用，尺寸不会太小，通常不会大于40px|
|大图标|**36-80**|通常作为装饰图标出现，用于提高页面的视觉效果|

---

## 六、按钮尺寸（第6张）

按钮的大小主要关注高度，宽度通常由内容决定。按钮是整个B端参数定义中的基石，其它控件的尺寸需要参照它的数值定义。

|   |   |   |
|---|---|---|
|按钮类型|高度|说明|
|大按钮|**36-44**|应用在权重最高、最需要用户关注的地方，使用频次不会高，最大建议控制在44左右|
|常规按钮|**28-36**|高频常用的按钮，鼠标操作中较为舒适的尺寸，再大容易影响排版和界面美观|
|小按钮|**20-28**|到20已经属于比较极端的情况，再小就不推荐使用|
|标签|**16-32**|样式和按钮非常接近，有些能点击有些只是信息展示；最小标签可以比按钮再小一点，最大尺寸不能超过常规按钮|

---

## 七、输入框尺寸（第7张）

输入框是按钮之外第二重要的控件，它决定了其它表单控件的尺寸，也直接影响后续级别更高的组件尺寸定义。

|   |   |   |
|---|---|---|
|输入框类型|高度|说明|
|小输入框|**20-28**|权重较低的输入框，高度和小按钮保持一致，才能水平并排|
|大输入框|**32-44**|高度由前面选择的某个常规按钮或大按钮的尺寸决定|
|下拉菜单 / 日期选择等|**20-44**|使用输入框样式的其它控件类型，需要沿用前面使用的输入框高度尺寸，保证完整表单中有统一的高度和视觉效果|

**小Tips**：常规项目中，输入框只需要使用 **2种尺寸** 就够了，并将这些尺寸尽可能复用到其它同类控件中去，即方便又统一。

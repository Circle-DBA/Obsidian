

```
┌──────────────┬─────────────────────────────────────┐
│              │ Header（仅右侧）Logo｜搜索｜主题｜通知｜用户 │
│ 左侧【通顶】  ├─────────────────────────────────────┤
│ 侧边栏       │                                     │
│ 一级 + 二三级 │ 右侧 SidebarInset 主内容区           │
│ 常驻完整菜单树 │ 表格、表单、卡片、业务页面          │
│              │                                     │
└──────────────┴─────────────────────────────────────┘
```

> 结构要点重申：左侧侧边栏从视口最顶端直通底部；Header 只在右侧列顶部，不跨到左边侧边栏；侧边栏内**同时承载一级模块、二级分组、三级页面**，整棵菜单树常驻，不是动态替换。

## ✅ 一级菜单配套方案（适配基座 + 插件模块化后台）

### 1. 一级菜单数据源规则

- 来源：基座 + 插件注册元数据，后端聚合生成，前端不硬编码
- 每个插件（博客、社区）注册时上报：`code、label、icon、sort、permissionPrefix、children（二三级菜单）`
- 过滤逻辑：
    1. 模块全局开关禁用 → 整条一级菜单隐藏
    2. 当前用户没有该模块访问权限 → 整条一级菜单隐藏
- 排序：基座一级菜单靠前（系统管理、权限、配置、CMS），业务插件一级菜单在后，sort 字段控制顺序

### 2. 一级菜单交互规则（侧边内）

1. 一级菜单两种形态可选（二选一，全局统一）
    - 模式 A（推荐，中台常规）：一级点击，**展开 / 收起自己下属的二级分组**；选中子路由时，自动展开所属一级、二级
    - 模式 B：一级仅作为路由入口，点击直接跳模块首页，下属二级自动展开
2. 状态记忆：
    - 一级展开 / 收起状态，和二级折叠状态分开存储
    - key 命名空间：`sidebar-collapse:menu-${menuId}`，不区分模块（因为是单棵常驻树）
3. 高亮规则：
    - 访问三级页面，路由匹配 → 对应三级高亮；自动向上冒泡，父二级、父一级保持展开
    - 一级本身不做高亮底色，仅下属路由激活时，一级文字可保持 `text-primary`

### 3. 一级菜单视觉规范（沿用亚奥扁平 /shadcn）

- 行高统一 40px，icon 16px，文字 14px
- 一级菜单：不额外加大字号、不加粗；和二级视觉区分仅靠缩进、chevron 箭头
- 一级缩进：0px；二级缩进 12px；三级缩进 24px
- 选中态只给最终三级页面：`bg-primary/10 text-primary`；父级只改文字色，不加背景
- 箭头：chevron-right，展开旋转 90°，150ms ease-linear

## ⚠️ 方案 1 重点注意点（避坑清单）

### 布局层面

1. 左侧侧边栏一定是 `h-full` 通顶，Header**绝对不能横跨侧边栏上方**，这是和老版本方案 1 最大区别
2. 侧边栏支持收缩为 64px 图标模式，收缩后依然通顶；收缩模式下：只显示一级图标，hover 弹出悬浮菜单面板展示二三级
3. 侧边和右侧内容区之间竖分割线，整高连续，不能断
4. 右侧 Header 承载：LOGO、全局搜索、主题切换、通知、用户下拉；**不要放模块 Tab**（一级全部在侧边）

### 菜单 & 权限层面

1. 菜单是**单棵常驻树**，和方案 4 核心区别：方案 4 切 Tab 换整棵菜单；方案 1 菜单一直都在，只是控制展开收起
2. 权限点前缀保持 `blog:xxx` / `community:xxx`，后端按权限过滤菜单节点，无权限节点直接剔除
3. 插件新增一级菜单，后端自动合并进菜单树，前端无需改路由硬代码
4. 路由守卫：路由只负责高亮，不销毁重建菜单 DOM

### 体验层面

1. 菜单展开状态是全局持久化，刷新页面、切换路由，各级展开记忆保留
2. 菜单树不能无限层级，严格限制最多三级：一级模块 → 二级分组 → 三级页面
3. 一级数量上限建议：**5–15 个**；超过 15 个，强烈建议改用方案 2 双轨导航，避免侧边一级过长滚动疲劳
4. 全局搜索：右侧 Header 的搜索，支持跨所有一级模块的菜单、页面搜索，搜索结果直接定位路由

### 工程实现层面

1. 路由全部注册在基座，插件路由动态注册，路由前缀：`/system`、`/cms`、`/plugin/blog`、`/plugin/community`
2. 侧边栏用 shadcn `Sidebar + SidebarMenu + Collapsible + SidebarMenuSub`，不要手写 div 折叠
3. 收缩模式（64px）悬浮面板，也要复用同一套菜单组件，保证样式统一

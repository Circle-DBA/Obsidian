# ④ 极简高对比（代码编辑器风 / 程序员后台）

|项目|内容|
|---|---|
|编号|④|
|核心气质|专注代码阅读|
|色相基调|翠绿|
|视觉压力|中偏高|
|最适配场景|日志、脚本、代码仓库、CI/CD|
|备注|深底高对比、等宽字体为主|

## 风格说明

气质：类似 VS Code / IDE 主题，强对比，专注代码、日志、脚本管理。

与「标准工业风」差异：工业风兼顾表单、表格，靠线条精密分层；本风格背景极深、文字对比度拉满，信息密度由字体而非组件承担，优先长文本与代码阅读。

## 质感要点

- 背景很深（暗色接近纯黑），文字对比度拉满；
- 主色高饱和翠绿（原 IDE 风常用蓝紫，本项目禁用蓝 / 深紫，故改用翠绿）；
- 很少卡片：`--card` 与 `--background` 接近，靠 `--border` 极简细线；
- 正文 / 代码区绑定等宽字体（`--font-mono`）；
- 圆角偏小（4px），分割线极简；
- 适合以文本 / 代码为主的专项后台，对表单 / 营销类页面不友好。

## 通用规则

- 遵循 shadcn 标准 CSS 变量命名，亮色 / 暗色成对配套；
- 功能色降饱和：砖红危险、土黄告警、墨绿成功；
- 主色只用于激活态、按钮、焦点环、高亮文字；
- 等宽字体由组件层 `--font-mono` 变量控制，切换风格时一并替换。

## 配色明细

> 色值统一为 hex，含 `--destructive / --warning / --success` 语义色。等宽字体栈建议：`"JetBrains Mono", "Fira Code", ui-monospace, Menlo, Consolas, monospace`，在组件层绑定正文 / 代码区。

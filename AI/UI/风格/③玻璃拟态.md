# ③ 玻璃拟态（轻磨砂 Glassmorphism）

|项目|内容|
|---|---|
|编号|③|
|核心气质|现代轻盈门户|
|色相基调|青|
|视觉压力|中|
|最适配场景|开发者门户、开放平台、品牌 SaaS、大屏配套|
|备注|半透+磨砂；表格/日志区建议回退实底|

## 风格说明

气质：现代、轻盈，偏对外开放平台、门户后台；半透明卡片 + 背景模糊 + 细边框，浅色背景好看，暗色效果尤其好。

与「标准工业风」差异：工业风是不透明实底 + 硬分割线；本风格是透光层叠，层次感来自透明度与模糊而非线条，背景需有色彩层次才能体现磨砂质感。

## 质感要点

- 卡片半透明 + `backdrop-filter: blur` + 细边框；
- `--card` 给实色 hex 作为降级，实际玻璃层用 `rgba` + 模糊（由组件层覆盖实现）；
- `--background` 要有层次（浅色带色彩底 / 暗色深色），否则磨砂无意义；
- 主色可稍鲜亮（青），与透底形成对比；
- **短板**：表格、密集数据面板可读性下降，表格 / 日志区建议单独回退为实底卡片。

## 通用规则

- 遵循 shadcn 标准 CSS 变量命名，亮色 / 暗色成对配套；
- 功能色降饱和：砖红危险、土黄告警、墨绿成功；
- 主色只用于激活态、按钮、焦点环、高亮文字，不做大面积铺色；
- 半透明、模糊无法用 hex 表达，由组件层 `--glass-bg` / `--glass-blur` 变量实现。

## 配色明细

> 色值统一为 hex，含 `--destructive / --warning / --success` 语义色。`--card` 为实色降级值，实际玻璃层用 `rgba(255,255,255,0.7)` + `backdrop-blur`（亮色）/ `rgba(19,78,74,0.6)`（暗色），在组件入口层覆盖。

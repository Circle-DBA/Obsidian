# 二、风格 & 配色方案总结（剔除布局 / 结构内容，只保留视觉规范、质感、配色规则）

## 统一基础质感规范（所有 9 套主题共用，不变）

1. 基底：哑光平涂，**禁止渐变、玻璃拟态、磨砂、高光、浮雕、内阴影**；卡片默认无阴影，仅 hover 可使用极淡弱阴影。
2. 分层手段：优先使用 1px 实线分割线做分层，不依赖阴影分层；线条统一等粗，只用实线，不用虚线。
3. 圆角：全局统一 `4px` 小半径，不使用大圆角、胶囊圆角。
4. 图标：Lucide 线性图标，`strokeWidth=1.5`，统一线条图标，禁用填充图标、彩色图标。
5. 文字：字重仅 400（常规）、500（标题），禁止 600 及以上粗字；无描边、发光效果。
6. 交互反馈：hover 仅变色，不放大、不上浮、无弹跳动效；激活选中使用主色低透明度底色叠加，不使用实色块。
7. 滚动条：原生细滚动条，不做异形美化。
8. 禁用项：背景纹理、噪点、点阵、图片背景；花哨加载动画，仅保留极简线条 / 点状加载。

## 配色体系通用规则

1. 全部遵循 shadcn 标准 CSS 变量命名，亮色、暗色成对配套，同一色相只调整明度，切换明暗主题不会跳色。
2. 所有主题均为**低饱和 “灰裹彩” 思路**，功能色降饱和：砖红警告、土黄告警、墨绿成功，避免荧光亮色刺眼。
3. 主色使用约束：主色只用于激活态、按钮、焦点环、高亮文字，不做大面积铺色。
4. 切换逻辑：基座布局、菜单组件、Tab 组件完全不需要改动，切换主题只替换一套 CSS 变量。
5. 权限 / 菜单逻辑不受主题影响，主题只负责视觉表现，不改变交互逻辑。

## 9 套主题简要回顾

- A 工业蓝灰：默认主推，企业后台通用首选
- B 石墨黑绿：安全、运维、监控场景
- C 冷钢青灰：精密技术、开发者平台
- D 砂岩灰棕：暖调柔和，适合长时间内容编辑
- E 暗橙黑石：告警故障专项，视觉张力强，不建议全局默认
- F 极简炭灰：纯灰度，适合设备、机房监控，无彩色干扰
- G 深海青蓝：轻盈通透，年轻化技术中台
- H 灰调紫堇：差异化内容中台，避开千篇一律蓝色后台
- I 暗松苔绿：生态、园区、自然资源、资产管理类系统

## 落地建议

- 产品可开放主题切换器，只开放 2–3 套主推，不一次性全部放开，避免用户选择负担过重；
- 暗色模式优先给运维、监控、告警类用户，亮色模式作为办公默认；
- 同一后台内，不混用多套主题色，一套主题下成功 / 警告 / 危险状态色保持统一。

# ⑥ 硬核暗黑赛博（仅限专项模块）

|项目|内容|
|---|---|
|编号|⑥|
|核心气质|科技霓虹专项|
|色相基调|青 + 洋红|
|视觉压力|高|
|最适配场景|网络安全、攻防、流量监控、大屏附属|
|备注|仅暗色主推，勿作全站默认，易疲劳|

## 风格说明

气质：深色为主，细霓虹描边、弱发光，科技感强。

与「标准工业风」差异：工业风是中性精密、亮暗均衡；本风格是极端暗色 + 霓虹发光，纯科技向、情绪化，几乎只做暗色。

## 质感要点

- 几乎只做暗色：`--background` 极深近黑，`--card` 深灰，与背景同深，靠描边 + 微光分层；
- 主色用高饱和青，accent 用洋红点缀，细发光 ring；
- `--ring` 覆盖为带 `box-shadow` 的发光环（组件层 `--ring-glow` 变量）；
- `--border` 用主色 20% 左右细边；
- 字体偏细字重 + 等宽点缀；
- 亮色仅提供「赛博降级版」（白底 + 细彩边），不作为全平台默认；
- **不适合全平台默认**，长时间办公易视觉疲劳，只适合安全 / 运维专项模块。

## 通用规则

- 遵循 shadcn 标准 CSS 变量命名，亮色 / 暗色成对配套；
- 功能色降饱和：砖红危险、土黄告警、墨绿成功；
- 本风格主色（青 / 洋红）用于霓虹描边与发光，是其风格特征，可适度突破「不做大面积铺色」约束；
- 发光无法用 hex 表达，由组件层 `--ring-glow` / `--neon-text` 变量实现。

## 配色明细

> 色值统一为 hex，含 `--destructive / --warning / --success` 语义色。霓虹发光由组件层 rgba 阴影实现：亮色 `--ring-glow` 不启用，暗色 `0 0 0 1px rgba(34,211,238,.7), 0 0 12px rgba(34,211,238,.45)`。

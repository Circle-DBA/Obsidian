# ① 柔和新拟态（轻 Neumorphism，低强度）

|项目|内容|
|---|---|
|编号|①|
|核心气质|温润轻量化|
|色相基调|低饱和暖灰|
|视觉压力|低|
|最适配场景|轻量 SaaS、客户管理、会员后台、轻 OA|
|备注|靠软阴影分层，无硬边；不适合高密度监控|

## 风格说明

气质：温润、轻量化，弱凸起弱凹陷；不是厚重老拟态，阴影柔和、线条少。

与「标准工业风」差异：工业风靠 1px 硬分割线精密分层、无阴影、4px 圆角、平涂无渐变；本风格靠一对柔和对侧阴影区分卡片，几乎无硬边框，圆角偏大，视觉温度更高、信息密度更低。

## 质感要点

- 背景比卡片深一档以衬托凸起，靠柔和对侧阴影（左上高光 + 右下投影）分层，几乎无硬边框；
- 圆角偏大（8px），无硬边框，线条少；
- 主色用低饱和中性色（暖灰），避免脏；
- 暗色阴影强度减半、对比降低，防止暗色发脏；
- 仅适合轻量系统，**不适合高密度运维监控页**。

## 通用规则

- 遵循 shadcn 标准 CSS 变量命名，亮色 / 暗色成对配套，同一色相只调整明度，切换明暗不跳色；
- 功能色降饱和：砖红危险、土黄告警、墨绿成功；
- 主色只用于激活态、按钮、焦点环、高亮文字，不做大面积铺色；
- 阴影不属于颜色变量，由组件层覆盖控制，切换风格时一并替换。

## 配色明细

> 色值统一为 hex，含 `--destructive / --warning / --success` 语义色（与「标准工业风」一致）。柔和阴影无法用 hex 表达，由组件层 `--shadow-soft` 变量实现。

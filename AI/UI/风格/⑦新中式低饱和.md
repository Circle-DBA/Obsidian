# ⑦ 新中式低饱和商务

|项目|内容|
|---|---|
|编号|⑦|
|核心气质|素雅内敛|
|色相基调|赭石 + 暖灰|
|视觉压力|很低|
|最适配场景|政务、国资、园区、文旅资产管理|
|备注|灰度克制，避开浓烈色彩|

## 风格说明

气质：素雅内敛，适合政务、国资、园区管理系统。

与「标准工业风」差异：工业风是冷调黑白灰 + 功能色；本风格是暖调低饱和色系（赭石主色 + 暖灰中性色），气质更内敛、文化属性更强。

## 质感要点

- 主色用低饱和赭石（暖棕），灰度克制，中性灰带暖调（baseColor 选 Stone / Taupe 而非冷 Neutral）；
- 留白充足，线条干净，不花哨，避开浓烈色彩；
- 圆角 6px；
- 暗色保持低饱和，**不反向提亮主色饱和度**；
- 图表色（`chart-*`）走同色系低饱和板（赭石 / 苔绿 / 赭红 / 黛青 / 砂色）；
- 标题可酌用衬线字体增强人文感，正文仍用无衬线保证办公可读；
- 个性强，与科技 / 互联网产品调性不搭，需确认甲方接受素雅路线。

## 通用规则

- 遵循 shadcn 标准 CSS 变量命名，亮色 / 暗色成对配套；
- 功能色降饱和：砖红危险、土黄告警、墨绿成功；
- 主色只用于激活态、按钮、焦点环、高亮文字，不做大面积铺色；
- 切换主题只替换一套 CSS 变量，基座布局与交互不受影响。

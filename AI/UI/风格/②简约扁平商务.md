# ② 简约扁平商务（现代企业 OA 风）

|项目|内容|
|---|---|
|编号|②|
|核心气质|干净清爽办公|
|色相基调|商务墨绿|
|视觉压力|低|
|最适配场景|OA、审批、人事、财务、行政后台|
|备注|留白大、分割线极淡，稳妥通用首选|

## 风格说明

气质：干净清爽、中性、低存在感，阿里 / 钉钉类 OA 常用路线。

与「标准工业风」差异：工业风强调线条、精密、控制台硬核感；本风格优先留白、降低压迫感，分割线极淡，偏向办公友好，不强调硬核感。

## 质感要点

- 留白更大，分割线极淡（亮色接近白的浅灰，暗色白色 8% 左右）；
- 主色饱和度适中（商务墨绿），不抢眼；
- 圆角 6px，少量卡片极淡轻阴影，不依赖阴影分层；
- hover 用主色极浅底色叠加，不上浮、无弹跳动效；
- 几乎无短板，是最稳妥的通用选择，但视觉个性弱，不适合需要强品牌识别的门户。

## 通用规则

- 遵循 shadcn 标准 CSS 变量命名，亮色 / 暗色成对配套，同一色相只调整明度，切换明暗不跳色；
- 功能色降饱和：砖红危险、土黄告警、墨绿成功（与「标准工业风」一致，跨主题不串色）；
- 主色只用于激活态、按钮、焦点环、高亮文字，不做大面积铺色；
- 切换主题只替换一套 CSS 变量，基座布局与交互不受影响。
